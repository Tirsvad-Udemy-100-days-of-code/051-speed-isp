# 051-speed-isp

Hari ke-51 *100 Days of Code* Udemy: bot Python yang mengukur kelajuan internet anda di speedtest.net menggunakan Selenium dan menyiarkan aduan di X (atau di perkhidmatan latihan "Y") apabila kelajuan lebih rendah daripada yang dijanjikan oleh penyedia perkhidmatan anda.

Wiki ini mengikut empat langkah dalam kuliah. Setiap halaman langkah memaparkan tangkapan skrin langkah tersebut dan diakhiri dengan **Apa yang kami peroleh**.

| Halaman | Baca apabila anda mahu |
| --- | --- |
| [Langkah 1: Akaun dan pemalar](Step-1-Account-and-Constants-ms) | Menyediakan akaun, kelajuan yang dijanjikan dan kelayakan log masuk |
| [Langkah 2: Cipta sebuah kelas](Step-2-Create-a-Class-ms) | Melihat cara `InternetSpeedTwitterBot` dibina |
| [Langkah 3: Dapatkan kelajuan internet](Step-3-Get-Internet-Speeds-ms) | Melihat cara Selenium membaca kelajuan daripada speedtest.net |
| [Langkah 4: Tweet kepada penyedia perkhidmatan](Step-4-Tweet-at-Provider-ms) | Melihat cara bot log masuk dan menyiarkan aduan |
| [Jalankan dan uji](Run-and-Test-ms) | Mencipta `.venv`, menjalankan bot dan menjalankan ujian |
