# 051-speed-isp

Day 51 of Udemy's *100 Days of Code*: a Python bot that measures your internet speed on speedtest.net with Selenium and posts a complaint on X (or on the practice service "Y") when the speed is below what your provider promises.

The wiki follows the four steps of the lecture. Each step page shows a screenshot of the step and ends with **What we gained**.

| Page | Read it when you want to |
| --- | --- |
| [Step 1: Account and constants](Step-1-Account-and-Constants) | Set up the account, the promised speeds and the credentials |
| [Step 2: Create a class](Step-2-Create-a-Class) | See how `InternetSpeedTwitterBot` is built |
| [Step 3: Get internet speeds](Step-3-Get-Internet-Speeds) | See how Selenium reads the speed from speedtest.net |
| [Step 4: Tweet at the provider](Step-4-Tweet-at-Provider) | See how the bot logs in and posts the complaint |
| [Run and test](Run-and-Test) | Create the `.venv`, run the bot and run the tests |
